# datasets_mirror

This repository caches copies of datasets whose original hosts have gone away. We keep them so that papers and teaching material that used the files remain reproducible.

The usual case is a server that has gone down. Sometimes the data was withdrawn rather than lost. If a dataset here should not be mirrored, open a [pull request](https://github.com/lawrennd/datasets_mirror/compare/main?quick_pull=1&template=removal.md) that deletes the relevant folder and complete the removal checklist (authority, rights holder, reason, and a public citation or a contact for a confidential ruling). We will then drop the corresponding download URL in [lawrennd/ods](https://github.com/lawrennd/ods).

Current download locations, and the original sources recovered from the history of pods, are recorded in [`pods/data_resources.yml`](https://github.com/lawrennd/ods/blob/main/pods/data_resources.yml) (and the matching JSON file) under the `original_urls` field.
